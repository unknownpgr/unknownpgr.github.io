Every school break, I try something new. Looking at my GitHub history, I think I have been doing this since around the summer break of my senior year in high school. After entering university, I studied ARM embedded systems during the summer break of my first year, and I wrote a paper over the winter break.

Now that it was the summer break of my second year, I browsed around the internet, thinking I ought to start something new again. Embedded systems are fairly low-level, so I decided it was time to study something high-level as well. I also wanted to try developing something with broader applications, so I began studying web development.

I already knew how to work with HTML / CSS / JS / Node.js ... and so on, but the web industry seems to be a field where something new comes out every six months, so there is always plenty to learn.

Anyway, I looked into what was popular at the time and came across keywords like React, Vue, Angular, and Bootstrap. Of course, back then I had ab-so-lutely no idea what any of those things were. I only knew they had something to do with the web...I guess?

After doing more research, I learned that React / Vue / Angular were similar JS frameworks / libraries, while Bootstrap was a library that made it easy to style UIs.

## Getting Started with Bootstrap

Bootstrap seemed like the most approachable option, so I started with that. Actually, I had begun learning Bootstrap shortly before the break started. Its structure was simple, its usage was intuitive, and the official documentation was well written, so I was able to learn it quickly. Being able to create polished-looking UIs this easily...was a bit of a culture shock. (How did I not know about something this useful...)

## Getting Started with React

Of React / Vue / Angular, I decided to start with React. (Because React had the coolest-sounding name...) React was not quite so easy. It was a little difficult to understand how it worked in the first place. I was rather surprised by how few articles there were online that explained how React worked in simple terms.

So I went straight to Kyobo Book Centre, bought a book, and read it. It was Park Ho-jun's [**The Definitive Guide to React Programming**](http://www.yes24.com/Product/Goods/87631428), and I liked it because it clearly explained everything from principles and applications to Redux.

After finishing the book and following a few hands-on exercises, I learned how to build web pages with React and how to create a single-page application using React Router. This was around July 7 or 8.

# Where Could I Use These...?🤔

Once you have learned something, you need to put it to use. You can never fully master programming just by reading books. That is why I started a GitHub blog. React and Bootstrap are both frontend libraries, and I had already planned to make a GitHub blog for my portfolio or as a development journal during this summer break.

This blog was the result. I began working on it in earnest on July 12, and since I am writing this post on July 25, it took me about two weeks to build. Now, I am going to start documenting its development right here on the blog I built myself.
